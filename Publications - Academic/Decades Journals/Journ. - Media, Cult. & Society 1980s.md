# Media, Culture & Society — 1980s (Vol. 1–11, 1979–1989)

Note: 1979 (Vol. 1) is included in this file even though it is technically the tail end of the 1970s, since there is no standalone 1970s file. Entries are listed in order of appearance within each issue, not alphabetized, and are not deduplicated across an issue — an author appears again if they are credited on more than one entry in the same issue. Entries with no credited author shown on the journal's table-of-contents page (e.g. some editorials, a diagram, a bibliography, a "transcription conventions" note, an uncredited book-review roundup) are omitted from the bullet list for that issue.
